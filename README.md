# JavaScript Projects 🟨

A collection of small web projects built with HTML, CSS, and JavaScript to practice core JavaScript concepts, DOM manipulation, API integration, and interactive user interfaces.

---

## 📂 Projects

| Project | Description |
| --- | --- |
| [📖 Dictionary](./dictionary) | A simple dictionary web app that lets users search for words and view their meanings. |
| [✊ Rock Paper Scissors](./rock-paper-scissors) | An interactive Rock Paper Scissors game against the computer, with score tracking. |

### 📖 Dictionary
A simple dictionary web application that allows users to search for words and view their meanings.

**Concepts practiced:**
* JavaScript DOM manipulation
* API integration
* Asynchronous JavaScript
* Fetch API
* Dynamic content rendering
* User input handling

### ✊ Rock Paper Scissors
An interactive Rock Paper Scissors game where users play against the computer and track their scores.

**Concepts practiced:**
* JavaScript functions
* Conditional logic
* Event handling
* DOM manipulation
* Random number generation
* Game state management

---

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript (ES6+)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/sadhana-0705/javascript-projects.git
```

Navigate into the project:

```bash
cd javascript-projects
```

Open any project folder and launch its `index.html` file in a browser.
